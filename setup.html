# NIGHT RUNNER: NEON PURSUIT

Готовий код аркадної 3D-гри для Telegram Mini Apps. Three.js 0.170.0 включено локально. Збірка для запуску не потрібна.

## Почніть тут — публікація з iPhone

1. Збережіть ZIP у «Файли» на iPhone. Натисніть ZIP — iOS створить розпаковану папку.
2. Відкрийте всередині **phone-ready**. Для найпростішої публікації потрібні тільки **index.html**, **config.js**, **setup.html**. Не завантажуйте сам ZIP як сайт: GitHub Pages його не розпаковує.
3. У Safari відкрийте https://github.com/new, увійдіть, створіть публічний репозиторій `night-runner`, додайте README. За потреби в меню Safari «аА» / меню сторінки увімкніть «Версія для комп’ютера».
4. У репозиторії натисніть **Add file → Upload files → choose your files → Browse / Огляд**. Виберіть три файли з `phone-ready` і натисніть **Commit changes**. Файли мають лежати безпосередньо в корені репозиторію, а не в папці phone-ready.
5. **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Дочекайтеся успішного deployment у вкладці Actions. Відкрийте HTTPS-адресу, показану GitHub Pages (зазвичай `https://ВАШ-ЛОГІН.github.io/night-runner/`). Спочатку можна грати як гість.
6. Відкрийте на цьому ж сайті **setup.html**: до адреси гри допишіть `setup.html`. Там є код Worker, SQL та генератор конфігурації. Жодних токенів у цю сторінку вводити не потрібно.

### Cloudflare D1

7. У Safari відкрийте https://dash.cloudflare.com/. Створення/вхід в обліковий запис виконайте самостійно. Назви розділів інтерфейсу Cloudflare можуть змінюватися.
8. **Storage & databases → D1 SQL Database → Create database**. Назва, наприклад, `night-runner-db`.
9. Відкрийте базу → **Console**. На вашій сторінці `setup.html` натисніть «Копіювати SQL», вставте в консоль D1 та виконайте. Якщо консоль приймає лише один SQL-запит за раз, виконуйте блоки по одному, розділяючи за `;`. Схема повторно виконується без видалення рекордів.
10. Перевірте: `SELECT name FROM sqlite_master WHERE type='table';` — повинні бути profiles, runs, best_scores, rate_limits, schema_migrations.

### Cloudflare Workers

11. **Workers & Pages → Create application → Create Worker / Start with Hello World → Deploy**. Назва, наприклад, `night-runner-api`.
12. Відкрийте Worker → **Edit code**. Замініть стандартний код повним вмістом **backend/worker-dashboard.js**; його також можна скопіювати кнопкою на `setup.html`. Це один готовий ES module без імпортів і npm. Збережіть та **Deploy**.
13. **Bindings → Add binding → D1 database**. Ім’я змінної строго **DB**. Виберіть створену базу.
14. **Settings → Variables and Secrets**: додайте **BOT_TOKEN** як **Secret**, значення — токен вашого Telegram-бота. Додайте звичайну змінну **ALLOWED_ORIGIN** зі значенням `https://ВАШ-ЛОГІН.github.io` — без шляху `/night-runner/` і без кінцевого `/`. Повторно Deploy.
15. Відкрийте URL Worker + `/api/health`. Очікується `{"ok":true,"rulesVersion":1}`. Цей запит підтверджує доступ до D1, але ще не перевіряє Telegram-авторизацію.
16. На сторінці `setup.html` введіть HTTPS URL Worker, натисніть «Завантажити config.js». Збережіть файл у «Файли». У GitHub знову Upload files → завантажте новий **config.js** поверх попереднього → Commit. Якщо iOS додала суфікс на кшталт `config (1).js`, спочатку перейменуйте файл точно на `config.js`.
17. Для очищення прострочених незавершених сесій додайте в Worker **Settings → Triggers → Cron Trigger**: `0 3 * * *`. Успішні результати цей обробник не видаляє.

**Обчислювальний бюджет.** Workers Free має обмеження CPU на запит. Повторення дуже довгого заїзду може перевищити його. Для стабільного публічного рейтингу рекомендовано Workers Paid з CPU limit щонайменше 1000 ms; оплата інфраструктури — власником, гра для гравців безкоштовна. Перед запуском перевірте `/run/finish` на реальному тарифі та метрики CPU. Не стверджу, що Free гарантовано витримає всі заїзди. Ліміти: https://developers.cloudflare.com/workers/platform/limits/.

### Telegram

18. В офіційному **@BotFather** виконайте `/newbot`, задайте назву й username. Токен зберігайте тільки в секретах Worker; не додавайте його в GitHub, config.js, setup.html або повідомлення з кодом.
19. `/mybots` → ваш бот → **Bot Settings → Configure Mini App** / **Main Mini App**: вкажіть HTTPS-адресу GitHub Pages. Якщо кнопки мають інші назви, скористайтеся підказками поточного BotFather.
20. Там само налаштуйте **Menu Button**, або командою `/setmenubutton`: оберіть бота, введіть назву «Грати» та адресу гри.
21. Відкрийте гру **через кнопку бота або Main App**, а не просто URL у Safari. На першому рейтинговому запуску підтвердьте нікнейм. Для повторного запуску після збереження натисніть «Грати» або «Виклик дня».
22. Завершіть заїзд втратою трьох одиниць міцності. Результат має отримати повідомлення «Перевірено й збережено в рейтингу». Відкрийте три таблиці, перевірте власну позицію. У D1 перевірте `SELECT nickname FROM profiles;` і `SELECT scope, period, score FROM best_scores;`. Звичайний заїзд входить у Weekly/All-time; Daily — також у Daily.
23. Примусово згорніть Telegram під час заїзду: після повернення має залишитися пауза, а очки не повинні зростати. Перевірте нижній свайп угору, утримання гальм і всі мови.

### Якщо Safari незручно працює з файлами

Папки в iOS file picker не завжди можна завантажити рекурсивно зі збереженням структури. Саме тому `phone-ready` містить тільки три файли в одному рівні. Не потрібно встановлювати редактор чи відтворювати src/vendor. У Cloudflare увімкніть «Версія для комп’ютера», поверніть телефон горизонтально та відкрийте Edit code. Якщо кнопка копіювання не працює, натисніть текстове поле коду, «Вибрати все → Копіювати». Роботу редактора Cloudflare саме на фізичному iPhone в цьому середовищі не перевірено; у разі проблем залишається браузерний GitHub Codespaces, але це складніший запасний шлях, не вимога до запуску.

## Повна модульна версія

Корінь архіву містить читабельні вихідні файли. `index.html`, `style.css`, `config.js`, `src/`, `vendor/` можна розмістити на будь-якому статичному HTTPS-хостингу без збірки. Шляхи відносні й підтримують підкаталог GitHub Pages. Не відкривайте ES Modules через file://: потрібен HTTP(S).

`phone-ready/index.html` — та сама гра зі стилями й модулями, включеними через import map та data URL; `config.js` залишається окремим і доступним для редагування. Підтримуються сучасні браузери з WebGL2 та import maps (iOS Safari 16.4+ для однофайлового комплекту). Для старіших браузерів використовуйте модульну версію; дуже старі WebView/WebGL1 не підтримуються Three.js 0.170.0.

## Керування

- Свайп ліворуч/праворуч — одна смуга. Свайп угору — Nitro від 30%.
- Тап у нижніх 31% — гальма на 0,4 с. Нерухоме утримання від 120 ms — безперервне гальмування.
- Після переходу утримання у свайп гальма скасовуються; Nitro має пріоритет. Гальма під час Nitro припиняють прискорення.
- A/D, ←/→ — смуги; W/↑ — Nitro; S/↓/Space — гальма; Esc — пауза.
- Три удари завершують заїзд; між ними 1,8 с захисту. Поліція з’являється після 650 м.
- Метр/секунда — внутрішня одиниця; HUD відображає км/год. Облік на 60 Hz незалежно від FPS.

## Онлайн та обмеження

- Це не розгорнутий публічний сервіс: API початково порожній. Після налаштування працюють справжні записи D1. Без Telegram граєте як гість; localStorage містить лише персональний рекорд/налаштування.
- Сервер перевіряє HMAC initData, вік авторизації, власника сесії, реальну тривалість, повторні подання і відтворює всі команди. Клієнтське поле score ігнорується.
- Це **не захист від ботів/макросів/автопілота**: легальну послідовність команд можна обчислити програмно, а відомий Daily seed вивчити. Сервер підтверджує можливість результату за правилами, а не людське походження керування.
- Сесія максимум 30 хв активного часу, термін подання 1 година від старту. Авторизація initData дійсна до 2 годин; після цього повторно відкрийте Mini App.
- Тиждень починається в понеділок 00:00 UTC; Daily — о 00:00 UTC. Результат належить дню/тижню **початку** заїзду. Рівні очки сортуються за часом досягнення, потім внутрішнім ID. Назовні ID не повертається.
- Збереження результату і рекордів відбувається в транзакції D1.batch. Повторне подання того самого replay ідемпотентне; іншого — відхиляється.
- Stars навмисно показують тимчасову недоступність: платіжний webhook та інвойси не підключені. Немає фальшивого платежу, реклами чи платних характеристик.
- 3D-гараж — обертання моделі на платформі, не окрема деталізована кімната. Світ містить компактні модульні варіації, не чотири великі карти.
- Розширена адаптація ефектів, повноцінні тунелі, вода з відбиттями, зміна смуг AI і складні частинки не входять у цю реалізацію. Якість змінює роздільність і дальність відображення; дорогого постпроцесингу немає.

## Оновлення без втрати рекордів

Замінюйте статичні файли у тому самому GitHub-репозиторії. Збережіть ваш API_URL. У Cloudflare замінюйте лише код Worker, зберігайте ту саму D1 binding **DB**, BOT_TOKEN, ALLOWED_ORIGIN. **Не видаляйте базу та не виконуйте DROP TABLE.** `schema.sql` — міграція 001 із CREATE IF NOT EXISTS. Наступні міграції додавайте окремими нумерованими файлами та фіксуйте у schema_migrations. Перед структурними змінами зробіть резервну копію/експорт D1 і перевірте можливість відновлення.

Клієнтська simulation.js та вбудована серверна копія мають збігатися. При зміні правил підніміть RULES.version, одночасно оновіть клієнт та Worker; незавершені старі сесії буде відхилено. Для чесного порівняння суттєво змінених правил потрібен окремий сезон, а не стирання старих рекордів. У README збережено інструкцію для поточної версії 1.

## Перевірки

Дивіться **QA.md** — точний перелік виконаних тестів та обмежень перевірки. **ART.md** — художня реалізація. **backend/README.md** — контракт API. Папка `tests` призначена для розробника; вам не потрібно запускати Node.js на iPhone.
